Governança & ERP

Inventário e Governança de Fontes Protheus

Desenvolvimento de ferramentas para inventariar fontes ADVPL/TLPP e comparar arquivos disponíveis com objetos compilados no RPO, identificando divergências e apoiando a governança técnica do ERP.

  • TOTVS Protheus
  • RPO
  • Python
  • ADVPL/TLPP

Visão geral

Em ambientes ERP com histórico de customizações, manter a rastreabilidade entre os objetos compilados e seus respectivos arquivos-fonte representa um desafio importante para a sustentação e evolução dos sistemas.

O projeto surgiu da necessidade de mapear os objetos existentes no repositório RPO do TOTVS Protheus e confrontá-los com os arquivos ADVPL/TLPP disponíveis, permitindo identificar divergências e pendências de organização.

O desafio

A existência de objetos compilados no repositório do ERP não garante, por si só, a disponibilidade e a correta identificação de seus respectivos arquivos-fonte.

Era necessário construir um inventário que permitisse visualizar os objetos presentes no RPO, relacioná-los aos arquivos disponíveis e identificar diferenças que exigissem análise.

O objetivo era melhorar a visibilidade sobre o código legado e estabelecer uma base confiável para as iniciativas de organização e controle de versão.

A solução técnica

Foi desenvolvida uma solução em Python para realizar o inventário técnico dos arquivos-fonte e compará-los com informações extraídas do repositório RPO do TOTVS Protheus.

  • Levantamento dos arquivos-fonte disponíveis.
  • Processamento das informações extraídas do RPO.
  • Comparação entre os dois inventários.
  • Identificação de correspondências e divergências.
  • Geração de relatórios para análise.
  • Identificação de pendências para organização dos fontes.

O processo foi executado integralmente, fornecendo uma base estruturada para a organização dos arquivos e para as iniciativas de governança do ambiente de desenvolvimento.

O projeto utiliza inventários e metadados dos objetos compilados, sem recuperação ou descompilação do código-fonte original a partir do RPO.

Minha atuação no projeto

Atuei na análise técnica, definição dos critérios de comparação e desenvolvimento das ferramentas utilizadas para levantamento, processamento e organização dos inventários.

O trabalho envolveu a investigação dos recursos disponíveis para identificação de objetos compilados no RPO, o desenvolvimento da solução em Python e a análise dos resultados gerados.

A iniciativa teve como foco ampliar a visibilidade sobre os ativos de software, apoiar a manutenção de customizações e fornecer uma base técnica para a evolução da governança de fontes.

Fluxograma funcional

A comparação utiliza os dados extraídos e o inventário de arquivos-fonte; o Python não realiza leitura direta do RPO.

  • Origem A

    1. Repositório RPO do Protheus
    2. Extração de informações dos objetos compilados

  • Origem B

    1. Diretórios de arquivos-fonte
    2. Inventário de arquivos ADVPL/TLPP
  1. Processamento e comparação com Python
  2. Identificação de correspondências e divergências
  3. Geração de relatórios
  4. Base para organização e governança de fontes

Resultados alcançados

O inventário e o comparativo entre os objetos compilados no RPO e os arquivos-fonte disponíveis foram integralmente realizados.

A solução funcionou por meio de execuções no ambiente de desenvolvimento VS Code, permitindo identificar correspondências, divergências e pendências de organização.

Os relatórios gerados proporcionaram maior visibilidade sobre os ativos de software e estabeleceram uma base técnica para iniciativas posteriores de padronização e controle de versão.

Limitações e oportunidades de evolução

Embora a solução tenha atendido integralmente ao objetivo funcional, não foi realizado seu empacotamento como executável independente.

A execução permaneceu vinculada ao ambiente de desenvolvimento Python no VS Code.

Como evolução, seria possível disponibilizar uma versão independente, simplificando a utilização da ferramenta sem a necessidade de executá-la diretamente pelo ambiente de desenvolvimento.

Competências demonstradas

  • Análise técnica do TOTVS Protheus e de seu repositório RPO.
  • Desenvolvimento de ferramentas com Python.
  • Inventário de fontes ADVPL/TLPP.
  • Processamento e comparação de dados.
  • Identificação de divergências e inconsistências.
  • Organização de ativos de software.
  • Governança técnica de sistemas ERP.
